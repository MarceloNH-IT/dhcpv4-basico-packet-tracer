Encender la interfaz y darle una IP
Hacé clic sobre el Router0.

Andá a la pestaña que dice CLI (Línea de comandos, arriba a la derecha).

Te va a aparecer un texto y abajo una pregunta: Would you like to enter the initial configuration dialog? [yes/no]:. Escribí no y presioná Enter.

Presioná Enter de nuevo para que te aparezca el texto Router>

Escribimos comandos en la terminal configurando el Router0 asignando la IP en DHCP. 

configure terminal
ip dhcp excluded-address 192.168.10.1 192.168.10.10
ip dhcp pool MI_RED_LOCAL
network 192.168.10.0 255.255.255.0
default-router 192.168.10.1
dns-server 8.8.8.8
exit



Entrando a las PC0 y PC1 realizamos ping revisando que se conectan y no hay perdida de paquetes.

ping 192.168.10.12

PC1
